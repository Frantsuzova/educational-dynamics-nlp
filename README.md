# Educational Dynamics NLP

Пилотный исследовательский проект по анализу образовательной динамики на основе коротких текстовых ответов студентов с использованием методов обработки естественного языка (NLP).

В центре внимания — динамика понятийного аппарата студентов, способов построения объяснений и представлений о культуре на протяжении учебного курса. Анализ организован по четырём контрольным точкам (T0–T3) и двум взаимодополняющим направлениям: текстовые характеристики ответов и компоненты понимания культуры.

## Структура репозитория

| Путь | Содержимое |
| --- | --- |
| [`data/lexicons/`](data/lexicons/) | Словарь культурологических понятий и выражений (`cultural_concept_lexicon.csv`), сгруппированных по четырём компонентам модели. |
| [`data/processed/`](data/processed/) | Таблица рассчитанных признаков (`processed_responses.csv`) и описание её полей (`data_dictionary.csv`). |
| [`data/aggregated/`](data/aggregated/) | Сводные таблицы динамики: `text_metrics_dynamics.csv` и `concept_components_dynamics.csv`. |
| [`src/`](src/) | Python-код предобработки текстов, выделения n-грамм, словарного сопоставления, расширения словаря с Word2Vec, расчёта показателей и агрегирования результатов. |
| [`docs/methodology.md`](docs/methodology.md) | Дизайн исследования, определения показателей, формулы, параметры обработки и ограничения интерпретации. |
| [`docs/theoretical_framework.md`](docs/theoretical_framework.md) | Теоретическое обоснование четырёхкомпонентной модели понимания культуры. |

## Два направления анализа

**1. Характеристики текста:** понятийная насыщенность, абстрактность, связность и интерпретативность.

**2. Компоненты понимания культуры:** наследие и объекты; нормы и практики; смыслы и интерпретация; социальная система и связи.

Компоненты не являются взаимоисключающими: один ответ может содержать признаки нескольких компонентов одновременно.

## Как связаны данные и код

`src/` содержит инструменты для обработки текстов и расчёта признаков. Словарь из `data/lexicons/` используется для поиска понятий и многословных выражений; Word2Vec применяется для предложения семантически близких вариантов, требующих проверки перед включением в анализ.

`data/processed/processed_responses.csv` содержит уже рассчитанные показатели. Таблицы из `data/aggregated/` представляют их сводную динамику по контрольным точкам и когортам. **Обновление словаря само по себе не обновляет готовые таблицы:** для этого нужен повторный расчёт на исходных ответах.

Подробности методики и интерпретации результатов приведены в [`docs/methodology.md`](docs/methodology.md); теоретическая рамка — в [`docs/theoretical_framework.md`](docs/theoretical_framework.md).
